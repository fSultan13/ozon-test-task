# Миграции

Версионированные миграции: `000001_<name>.up.sql` / `000001_<name>.down.sql`.
Runner — golang-migrate v4.18.3: `DATABASE_URL=... make migrate-up`.
`make migrate-down` удаляет таблицу вместе с данными: использовать осознанно.
Compose применяет миграции отдельным сервисом до запуска API. API не выполняет DDL.

Первая миграция создаёт `links` и расширение `pgcrypto` (нужны права CREATE в БД).
Откат оставляет `pgcrypto`: расширение может использоваться другими таблицами.
Код уникален через PRIMARY KEY. Уникальный индекс SHA-256 ограничивает размер
ключа для URL до 8000 байт; HASH-индексы обеих строк обслуживают точный поиск.
Коллизия SHA-256 приводит к ошибке сохранения, а не возврату чужого URL.
